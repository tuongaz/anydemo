## Codebase Patterns
- `packages/canvas/src/index.ts` is the only public barrel — add new exports under the matching numbered section and keep it sorted (5 → 5b → 5c → 6 …).
- Biome's `organizeImports` enforces alphabetical order on import groups; sort sibling type-only imports by source path or the lint fails.
- `bun test <path>` only works from the repo root (the bun-test cwd-filter trips up nested paths in `apps/*` / `packages/*`).
- Adapter-layer types live in `packages/canvas/src/adapter/`. The canonical adapter shape is `CanvasAdapter` (throw-on-error); a non-throwing twin (`IoAdapter`) sits in a sibling file and is wrapped at the SeeflowCanvas prop boundary — never imported from the rendering layer.
- `bun run format` MUST run before `bun run lint` — Biome only emits fixes when `--write` runs, and `lint` is the gate.
