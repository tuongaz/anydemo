## Codebase Patterns
- Studio sources live in `apps/studio/src/` with co-located `*.test.ts` (Bun test). Run a single file with `bun test apps/studio/src/foo.test.ts` from repo root.
- Pub/sub modules follow the `createX(deps)` factory pattern (see `events.ts`): closure-captured state, `subscribe(fn)` returns an unsubscribe closure, throwing subscribers are caught + logged without affecting others.
- Quality gate order: `bun run format` (biome --write) → `bun run lint` (biome check) → `bun run typecheck` (fans out via concurrently).
- Typecheck needs `@seeflow/canvas` built first (`cd packages/canvas && bun run build`) because schema.ts imports `@seeflow/canvas/catalog` types from its dist.
- Biome strict on unused variables — use `// biome-ignore lint/correctness/noUnusedVariables: <reason>` when reserving a slot for an upcoming story.
- `noUncheckedIndexedAccess` is on — array access returns `T | undefined`; use optional chaining or guards.
