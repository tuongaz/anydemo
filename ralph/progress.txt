- `SessionRow` in `cloud/lambda/share/shared/sessions.ts` is the DDB row contract. - DDB UpdateExpression composition: `ADD tokenVersion :one SET lastActivity = :l, #ttl = :ttl` is valid — keywords (SET/ADD/REMOVE/DELETE) each start their own clause. Use `ReturnValues: 'UPDATED_NEW'` + read `Attributes.<field>` to get the post-increment value.

When you add a new UpdateCommand shape (e.g., `list_append(if_not_exists(...))`), extend the mock's branch list in sessions.test.ts AND keep ws-default.test.ts in sync if it routes the same expression.
- Peer JWT payload (`PeerPayload` in jwt.ts) round-trips through `mintPeerToken` / `verifyPeerToken`. Every test that mints a token (jwt.test.ts, ws-default.test.ts, ws-default.presence.test.ts) needs the new fields in its payload literal.
- HTTP-API share lambdas register via `mkShareLambda(id, file)` + an `httpApi.addRoutes(...)` call in `cloud/lib/seeflow-stack.ts`. Add the fn to the `for (const fn of [...])` loop to get `shareSessions.grantReadWriteData`. Anything that calls back into WebSocket (PostToConnection / DeleteConnection) also needs `shareWsApi.grantManageConnections(fn)`.
- HTTP-API share lambdas (non-WS) DON'T receive `event.requestContext.domainName/stage` for the WebSocket API — they must construct the ApiGatewayManagementApiClient endpoint themselves. Easiest: read `process.env.SHARE_WS_URL` (set by `sharedShareEnv`) and convert `wss://` → `https://`.
