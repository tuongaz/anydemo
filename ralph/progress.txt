- **Learnings for future iterations:**
  - The studio's active-sessions tracker (active.json) lives in the same `~/.seeflow/share-history/` directory as the per-session JSONL audit logs. Tests MUST inject `activeSessionsPath` (and use mkdtempSync) so they don't pollute the real user dir. The default path is `join(auditDir, 'active.json')` — but `auditDir` defaults to `~/.seeflow/share-history` so without an override, killAll/start would touch real disk.
  - `writeFileAtomic` (apps/studio/src/atomic-write.ts) does NOT create parent dirs — call `mkdirSync(dirname(path), {recursive:true})` first or the write throws ENOENT. This is documented in apps/studio/CLAUDE.md but worth re-noting.
  - The kill-switch flow writes `kill-switch` AuditEntries to EACH affected session's log via `auditLoggerFactory(sessionId, auditDir)` — so the factory MUST be safe to invoke for arbitrary sessionIds (it is: createAuditLogger validates via `isSafeSessionId` + lazy-mkdirs the file). Closing the new logger via `.close()` only awaits the in-process lock chain, no file handle is held.
  - cloud session-end behaviour: targets list = `hostConnId` (if non-null) + every peer connId. Order matters only for log assertion stability — happy-path test sorts the targets before comparing. The session row is deleted AFTER posting/deleting all conns so a partial failure leaves the row intact (next killAll will retry).
  - Local `require()` inside a test fn works in bun-test for opportunistic fs/os/path access without polluting top-level imports. The Biome formatter leaves these alone as long as they're inside a function body.
  - When mocking the relay's `/api/share/end` response for the "1 ok + 1 502" case, route by body substring (`body.includes('sess-b')`) rather than url, since every call hits the same endpoint. Don't rely on call ORDER — tracked sessions iterate in array order but tests shouldn't pin that contract.
  - When extending the `FakeShare` in api.test.ts, add the new method to both the `createFakeShare(init?)` parameter type AND the returned object literal. Default to a no-op `async () => ({revoked:0, failed:0})` so existing tests don't need to opt-in.
