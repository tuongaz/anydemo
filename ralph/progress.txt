## Codebase Patterns
- CSS @import must come before @tailwind directives in index.css
- Shadcn HSL token format: `--token: H S% L%` (no `hsl()` wrapper in the var definition)
- Canvas-specific rules in index.css live outside @layer blocks to maintain specificity over xyflow library defaults
- `bun run format` auto-converts single quotes to double quotes (Biome config)
- design.html uses the same shadcn HSL tokens as index.css; design aliases (--bg, --surface, etc.) point to `hsl(var(--shadcn-name))`
- `--border` clashes with shadcn's raw `--border` token name — all `var(--border)` usages must be wrapped as `hsl(var(--border))` in design.html
